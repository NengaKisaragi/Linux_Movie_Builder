# Linux Movie Builder — レイヤー編集版

Linux用のシンプルな4ウインドウ動画編集ソフトです。
Python 3 / PyQt5 / Pillow / FFmpeg / FFplay を使用します。

## 起動

`./start.sh` を実行、または `Linux Movie Builder.desktop` を開いてください。

## 4つのウインドウ

- **編集画面**：動画全体を表示する編集キャンバスと、保存・書き出し。
- **タイムライン**：素材の追加・テキスト作成・削除、動画・PNG・テキスト・全画面フィルタを時間とレイヤーで配置。音声は独立した行に表示。
- **プロパティ**：左の開始値・右の終了値、配置時刻・長さ・レイヤー、X/Y位置、拡大率、透明度、回転、音量、文字内容・文字色。各項目名を押すと、移動方法がプロパティ内に開きます。
- **プレビュー**：再生操作をしたときだけ、合成済みの動画と音声を再生。停止すると停止位置の映像を残します。

「ウインドウ」メニューで分割・統合・再表示ができます。タイトルバーをドラッグして分離・結合もできます。初回起動は1画面内に収まる統合配置で開きます。
配置は終了時に同じフォルダの`window-layout.ini`へ保存されます。この個人設定ファイルはGit管理対象外です。「ウインドウ」→「ウインドウ位置をリセット」で保存配置を消去して初期配置へ戻せます。

## Spaceについて

編集画面、タイムライン、プレビューでSpaceを押すと、現在位置から再生／停止します。再生・停止と1フレーム送りのボタンはタイムライン上部にあります。
**Spaceでは書き出しもプレビューMP4の生成もしません。** 画面と音声を直接ストリーミング再生します。
MP4ファイルを保存するのは「MP4 書き出し」またはCtrl+Eを操作したときだけです。
テキスト入力欄のSpaceは文字入力として扱います。

## 配置・編集

1. 素材の追加・テキスト作成・削除はタイムライン上部のボタンから行います。MP4・PNGなどをタイムラインへドロップすると、ドロップした時刻・レイヤーに置かれ、編集画面が更新されます。
2. タイムラインの右クリックからも素材・テキストを追加できます。文字列のドロップ、UTF-8の`.txt`ファイルにも対応します。
3. 編集画面の映像・PNG・文字をドラッグすると、位置を変えられます。
4. 拡大率・位置・文字サイズ・色はプロパティからも変更できます。
5. タイムラインの目盛りまたは空白をドラッグすると、その間ずっと編集画面が更新されます。
6. クリップの中央をドラッグすると、配置時刻とレイヤーが移動します。端をドラッグすると長さが変わります。クリップ上を右クリックすると中間点を追加・削除できます。
7. クリップ内部へ再生位置を移し「分割」でカットできます。空き時間までシークすると、編集画面は黒くなります。

レイヤー番号が大きい素材が手前です。同じレイヤーが重なる場合は後から追加した素材が手前に表示されます。中間点は水色の縦線で示します。選択したクリップは色が変わり、中間点がある場合はクリックした区間が明るく表示されます。再生カーソルを動かしても選択区間は変わりません。プロパティは素材種別に応じて表示され、映像・画像・テキストでは位置や拡大率など、音声では音量が編集できます。
編集座標は1280×720を基準とし、出力時には解像度に応じて拡大縮小します。X/Yは素材の中心座標です。
映像と画像の拡大率100%は、元の縦横比を保って画面内へ収まる大きさです。
テキストの100%は指定文字サイズです。透過PNGの透明部分も保ちます。

タイムラインの空き領域を右クリックし「フィルタを追加」から、シーンチェンジ・フェード・モザイク・ぼかしを選べます。フィルタは専用行にバーで表示され、バーの移動や端のドラッグで適用時間を調整できます。フィルタはプレビュー再生と書き出しの合成映像全体に適用されます。

タイムライン上部の「素材を追加」ボタンからの動画追加は、映像Layer 1の末尾へ連結します。
画像・テキストは現在の再生位置へ置きます。編集画面へのファイルドロップでは、その位置に中心を配置します。
音声は配置時刻と音量を調整できます。素材のない区間は黒・無音になります。

## 動画の設定と環境設定

新規プロジェクトは1920×1080、60 fpsです。「動画」→「動画の設定…」で変更でき、一覧にない解像度やフレームレートは「値を指定…」から入力できます。プロパティには出力設定を表示しません。
「ファイル」→「環境設定…」では、起動時に前回のウインドウ配置を復元するかを切り替えられます。

## プロジェクトとMP4

プロジェクトは`.lmb`形式です。中間点も保存されます。素材は相対パスで参照するため元ファイルを保持してください。
テキスト内容と配置・レイヤー・拡大率も保存します。旧版のプロジェクトも順番を保って読み込めます。
新しい保存形式は旧アプリでは開けません。

MP4はH.264/AACです。編集画面・直接再生・MP4出力は同じ配置を使用します。
書き出し中の編集は可能ですが、出力対象は書き出し開始時点の内容です。
キャンセル時には既存の出力ファイルを保持します。

## ショートカット

Ctrl+N 新規、Ctrl+O 開く、Ctrl+S 保存、Ctrl+Shift+S 名前を付けて保存、Ctrl+I 素材追加、
Ctrl+E MP4書き出し、Ctrl+B 分割、Ctrl+Z 元に戻す、Ctrl+Shift+Z やり直す、Delete 削除、Space 再生／停止。

## 現在の範囲

複数映像・画像・テキストと音声を重ねられます。トランジション、速度変更、キーフレーム、エフェクトは未実装です。
直接再生の処理はCPUで行うため、素材・レイヤーが多いと再生が追いつかないことがあります。
音声と映像は別プロセスで再生するため、環境の負荷により同期がずれることがあります。
長いテキストの描画領域は8192×4096pxまでです。アニメーションの移動方法は、移動なし・直線・加減速・曲線・瞬間・ランダム・反復から選べます。反復回数と曲線の強さもプロパティ内で調整できます。
