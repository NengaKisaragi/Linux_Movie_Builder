# Linux Movie Builder

バージョン 1.10

Linux向けのシンプルなデスクトップ動画編集ソフトです。
というかAviUtlのパクリソフトです。

タイムラインに動画・画像・テキスト・音声を配置し，プレビュー再生やMP4書き出しができます。

## 主な機能

- 編集画面，タイムライン，プロパティ，プレビューを分割表示
- 動画・画像・音声ファイルとテキストをタイムラインへ追加
- クリップの移動，トリミング，分割，中間点によるプロパティアニメーション
- 音声付きクリップの波形表示，音量調整，フェードイン・フェードアウト
- シーンチェンジ，フェード，モザイク，ぼかしの全画面フィルタ
- MP4（H.264/AAC）への書き出し

## AviUtl相当の機能（v1.10）

- **フィルタ効果**：映像・画像・テキスト・図形に複数の効果を重ねがけできます（プロパティの「フィルタ効果」、またはクリップの右クリック）。
  色調補正（明るさ・コントラスト・彩度・色相）、単色化、反転（左右・上下・輝度）、ぼかし、モザイク、シャープ、ノイズ、縁取り、シャドー、発光、
  クロマキー、クリッピング、色ずれ、周辺減光、エッジ抽出、残像。チェックで一時無効化、↑↓で適用順を変更できます。透過部分は保たれます。
- **フィルタ効果オブジェクト**：空き領域の右クリック →「フィルタを追加」→「フィルタ効果オブジェクト」で、そのレイヤーより下の合成結果全体に効果を掛けます。
- **合成モード**：通常・加算・減算・乗算・スクリーン・オーバーレイ・比較(明)・比較(暗)・差分。
- **図形**：四角形・角丸四角形・円・三角形・星・六角形。色・幅・高さ・ライン幅（0で塗りつぶし）を指定できます。
- **再生速度**：映像・音声を10〜1000%で再生（音声はピッチを保って伸縮）。素材の長さを超える場合は自動で長さを詰めます。
- **フェードイン／アウト**：映像・画像・テキスト・図形にも有効（不透明度に掛かります）。音声の**左右（パン）**も設定できます。
- **テキスト**：文字揃え（左・中央・右）と行間。
- **レイヤーの表示／ロック**：タイムライン左端の「表示」「ロック」を押して切り替え。非表示レイヤーは再生・書き出しにも含まれません。設定はプロジェクトに保存されます。
- **スナップ**：クリップの移動・長さ変更で、他クリップの端・再生位置・0秒に吸着します（Alt押下中は無効、タイムライン上部で切替）。
- **グリッド表示**：「表示」→「グリッドを表示」（Ctrl+G）。
- **書き出し**：MP4 (H.264 / H.265)、WebM (VP9)、WAV・MP3（音声のみ）。全体または範囲指定（先頭〜再生位置、選択クリップ）、画質と音声ビットレートを指定できます。
- **現在のフレームを画像で保存**：「ファイル」→（Ctrl+Shift+E）で出力解像度のPNGを保存。
- **キー操作**：←→で1フレーム、Shift+←→で1秒移動、Home／Endで先頭／末尾。

編集画面のプレビューは、各オブジェクトのフィルタ効果と合成モード（減算以外）を反映します。フィルタ効果オブジェクトと減算はプレビュー再生・書き出しで確認してください。
重い効果（発光・シャドー・フェードの多用など）は直接再生が追いつかないことがあります。

## 動作環境

- Linux
- Python 3
- PyQt5 5.15以降
- Pillow 9以降
- FFmpeg（`ffmpeg` と `ffplay` コマンド）

Debian / Ubuntuでは，次のシステムパッケージをインストールします。

```bash
sudo apt update
sudo apt install python3 python3-pyqt5 python3-pil ffmpeg
```

pipを使う場合は仮想環境を作成します。

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## 起動

GitHubの「Code」→「Download ZIP」から取得した場合，展開先で次を実行します。

```bash
bash ./start.sh
```

`start.sh` は `.venv` があればそのPythonで，なければシステムの `python3` で起動します。

## 基本操作

- 素材追加・テキスト作成・削除はタイムライン上部のボタンからおこないます。
- タイムラインの空白を右クリックすると，素材やフィルタを追加できます。
- フィルタは専用レーンのバーで表示されます。バーをドラッグして位置を変え，端をドラッグして長さを調整します。
- クリップ上を右クリックすると中間点を追加・削除できます。プロパティ値はタイムラインで選択した区間に対応します。
- 音声付きクリップにはタイムライン上に波形を表示します。選択後，プロパティの「フェードイン」「フェードアウト」で秒数を指定できます。
- タイムラインまたは編集画面でSpaceを押すと再生・停止します。フレーム送りボタンはタイムライン上部にあります。
- `Ctrl+E` または「ファイル」メニューからMP4を書き出します。

プロジェクトは `.lmb` 形式で保存されます。素材ファイルはプロジェクトと同じフォルダを基準に参照するため，プロジェクトと一緒に保管してください。

## ウインドウ配置

初回起動は1画面に収まる統合レイアウトです。配置は終了時に同じフォルダの `window-layout.ini` に保存されます。この個人設定ファイルはGit管理対象外です。「ウインドウ」→「ウインドウ位置をリセット」で保存配置を消去して初期状態へ戻せます。

## 制限事項

- Linuxデスクトップ向けです。Windows・macOS向けのパッケージは用意していません。
- リアルタイム再生はCPUを使用するため，素材やレイヤーが多いと再生が遅れる場合があります。
- FFmpegの機能・コーデックはインストールされているビルドに依存します。
