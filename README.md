# Linux Movie Builder

Linux向けのシンプルなデスクトップ動画編集ソフトです。タイムラインに動画・画像・テキスト・音声を配置し、プレビュー再生やMP4書き出しができます。

## 主な機能

- 編集画面、タイムライン、プロパティ、プレビューを分割表示
- 動画・画像・音声ファイルとテキストをタイムラインへ追加
- クリップの移動、トリミング、分割、中間点によるプロパティアニメーション
- タイムライン全体に適用するシーンチェンジ、フェード、モザイク、ぼかし
- MP4（H.264/AAC）への書き出し
- 初期出力設定は1920×1080、60 fps。動画メニューから変更可能

## 動作環境

- Linux
- Python 3
- PyQt5 5.15以降
- Pillow 9以降
- FFmpeg（`ffmpeg` と `ffplay` コマンド）

Debian / Ubuntuでは、必要なシステムパッケージを次のようにインストールできます。

```bash
sudo apt update
sudo apt install python3 python3-pyqt5 python3-pil ffmpeg
```

pipを使う場合は仮想環境を作成して導入します。

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## 起動

```bash
./start.sh
```

`start.sh` は `.venv` があればそのPythonで、なければシステムの `python3` で起動します。

## 基本操作

- タイムライン上部の「素材を追加」「テキスト」「削除」で素材を操作します。
- タイムラインの空白を右クリックすると、素材やフィルタを追加できます。
- フィルタは専用レーンにバーで表示されます。バーをドラッグして適用位置を変え、端をドラッグして長さを調整します。
- クリップ上を右クリックして中間点を追加・削除できます。中間点を含むクリップは、タイムライン上でクリックした区間のプロパティ値を編集します。
- タイムラインまたは編集画面でSpaceを押すと再生・停止します。フレーム送りのボタンはタイムライン上部にあります。
- `Ctrl+E` または「ファイル」メニューからMP4を書き出します。

プロジェクトは `.lmb` 形式で保存されます。素材ファイルはプロジェクトと同じフォルダを基準に参照するので、プロジェクトを移動するときは素材も一緒に保管してください。

## 制限事項

- Linuxデスクトップ向けです。Windows・macOS向けのパッケージは用意していません。
- リアルタイム再生はCPUを使用するため、素材やレイヤーが多いと再生が遅れる場合があります。
- FFmpegの機能・コーデックはインストールされているビルドに依存します。
