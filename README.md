# Linux Movie Builder

Linux向けのシンプルなデスクトップ動画編集ソフトです。
というかAviUtlのパクリソフトです。

タイムラインに動画・画像・テキスト・音声を配置し，プレビュー再生やMP4書き出しができます。

## 主な機能

- 編集画面，タイムライン，プロパティ，プレビューを分割表示
- 動画・画像・音声ファイルとテキストをタイムラインへ追加
- クリップの移動，トリミング，分割，中間点によるプロパティアニメーション
- シーンチェンジ，フェード，モザイク，ぼかしの全画面フィルタ
- MP4（H.264/AAC）への書き出し

## 動作環境

- Linux
- Python 3
- PyQt5 5.15以降
- Pillow 9以降
- FFmpeg（`ffmpeg` と `ffplay` コマンド）

Debian / Ubuntuでは，次のシステムパッケージをインストールします。

```bash
sudo apt update
sudo apt install python3 python3-pyqt5 python3-pil ffmpeg
```

pipを使う場合は仮想環境を作成します。

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## 起動

GitHubの「Code」→「Download ZIP」から取得した場合，展開先で次を実行します。

```bash
bash ./start.sh
```

`start.sh` は `.venv` があればそのPythonで，なければシステムの `python3` で起動します。

## 基本操作

- 素材追加・テキスト作成・削除はタイムライン上部のボタンからおこないます。
- タイムラインの空白を右クリックすると，素材やフィルタを追加できます。
- フィルタは専用レーンのバーで表示されます。バーをドラッグして位置を変え，端をドラッグして長さを調整します。
- クリップ上を右クリックすると中間点を追加・削除できます。プロパティ値はタイムラインで選択した区間に対応します。
- タイムラインまたは編集画面でSpaceを押すと再生・停止します。フレーム送りボタンはタイムライン上部にあります。
- `Ctrl+E` または「ファイル」メニューからMP4を書き出します。

プロジェクトは `.lmb` 形式で保存されます。素材ファイルはプロジェクトと同じフォルダを基準に参照するため，プロジェクトと一緒に保管してください。

## ウインドウ配置

初回起動は1画面に収まる統合レイアウトです。配置は終了時に同じフォルダの `window-layout.ini` に保存されます。この個人設定ファイルはGit管理対象外です。「ウインドウ」→「ウインドウ位置をリセット」で保存配置を消去して初期状態へ戻せます。

## 制限事項

- Linuxデスクトップ向けです。Windows・macOS向けのパッケージは用意していません。
- リアルタイム再生はCPUを使用するため，素材やレイヤーが多いと再生が遅れる場合があります。
- FFmpegの機能・コーデックはインストールされているビルドに依存します。
